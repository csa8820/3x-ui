# 伪站点、模板库与入站关联

“伪站点”是独立的面板功能。先创建和管理网站，再按需关联入站；不关联时保持原来的代理行为，无需安装 Nginx 或 Caddy。

功能目前支持 Linux/macOS 本机入站。模板、站点配置和证书均由承载入站的面板管理；远程节点需在对应节点的面板配置。任意协议均可配合独立网站端口，但同一个 TCP 端口能否同时提供网页与代理，取决于协议和传输方式。

## 创建网站

1. 打开侧栏 **伪站点**，点击 **创建伪站点**，或从 **模板库** 选择模板。
2. 填写站点名称、域名、网站端口、模板；内置模板可编辑标题（品牌名）和介绍。
3. 选择自动证书，或填写已有证书及私钥的文件路径；也可以点击“从面板设置证书”直接使用面板的证书。
4. 需要网站独立运行时开启 **独立监听**；准备与入站共用端口时保持关闭。
5. 保存后，站点作为可复用资源显示在列表中。列表显示关联数量、监听和证书状态。

自动证书采用 TLS-ALPN-01：域名需直接解析到服务器，允许 TCP 443，关闭 DNS 代理，并检查 AAAA 记录是否正确。不需要开放 80。勾选自动证书表示接受界面链接的 Let’s Encrypt 用户协议。

未开启独立监听且尚未关联入站的站点不会绑定公网端口或开始申请证书。

## 选择模板

| 来源 | 数量与使用方式 |
| --- | --- |
| 内置模板 | 8 套中文企业官网，离线可用：科技云服务、集团制造业、金融投资、专业服务（律所）、教育培训、消费品牌、新闻资讯门户、开发者文档。 |
| 自定义模板 | 点击“导入模板 ZIP”，导入任意已构建好的静态网站。 |

内置模板都是多板块的完整页面（导航、首屏、数据亮点、业务介绍、案例、新闻、多栏页脚），所有图形用 CSS 和 SVG 绘制，不加载任何外部字体、脚本或图片，访问时不会向第三方发出请求。站点“标题”会替换模板中的品牌名，“介绍”会替换首屏简介；留空则使用模板自带的虚构品牌和文案。页脚邮箱使用站点域名。

模板库支持按名称、分类搜索和预览。旧版本的英文模板（含 Start Bootstrap 目录）已移除，升级时已保存的站点会自动换成风格最接近的中文模板。

ZIP 应包含 `index.html` 和配套 CSS、图片等文件；支持外层目录及常见 `dist/` 构建目录。ZIP 上限 25 MiB，解包内容上限 100 MiB、最多 2000 个条目。拒绝越界路径和符号链接。仅作为静态文件提供服务，不执行 PHP、Node 或其他服务器脚本。

导入模板保留自身内容，标题和介绍设置仅作用于内置模板。预览使用禁用脚本的隔离 iframe；实际网站保留静态模板自身的浏览器脚本。

## 按需关联入站

编辑任意入站，打开 **伪站点** 页，选择一个站点，再选择端口配合方式。默认 **自动匹配**；选择“不关联伪站点”即可移除关联。

| 入站类型 | 自动匹配的方式 | 浏览器与代理如何配合 |
| --- | --- | --- |
| TLS + XHTTP / WebSocket / gRPC / HTTPUpgrade | HTTP 路径共用端口 | 内置 HTTPS 服务处理网页，独立路径转发代理请求。可用于兼容这些传输的 VLESS、VMess、Trojan 等协议。 |
| VLESS / Trojan + RAW(TCP) + TLS | RAW TLS 回落 | Xray 继续处理 TLS，普通浏览器请求回落到内置网站。 |
| REALITY | REALITY 本地目标站 | 站点作为本机 TLS 目标，普通浏览器请求显示网站，原有 REALITY 密钥与凭据保留。 |
| Hysteria、TUIC、WireGuard 等 UDP 协议 | 独立网站 / TCP-UDP 同号共存 | 网站使用 TCP HTTPS；代理继续使用 UDP，可使用相同端口号。此模式不提供 HTTP/3 网站伪装。 |
| 其他 TCP 协议，如普通 Shadowsocks、SOCKS、HTTP、MTProto | 独立网站 | 网站使用另外的 TCP 端口，不改写原有协议。 |

同一个 TCP 地址与端口不能由两个普通监听器同时占用。普通 Shadowsocks 等不兼容 HTTPS 分流的配置若与网站选择相同 TCP 端口，保存时会给出明确错误；调整网站端口即可关联。不能把所有协议无条件视为可在 443 上共用 HTTPS。

HTTP 路径共用会为根路径或空路径生成独立路径，保存后应更新客户端订阅。RAW TLS 回落需要已有证书，且 VLESS 的 `decryption` 必须为 `none`；需要 VLESS Encryption 时可选择 HTTP 传输、REALITY 或独立网站。

同端口共用时请关闭站点的“独立监听”，避免重复占用端口。自动证书仅支持公网 TCP 443；其他网站端口可使用已有证书。

## 修改、停用与迁移

在伪站点页面修改模板、标题、域名或证书，会同步更新已关联的入站配置。监听器自动协调更新，涉及 Xray 配置的变更进入面板现有的应用队列；客户端地址或 SNI 改变后需重新获取订阅。

停用或删除入站会停止其按需启动的站点监听；仍被其他入站使用或开启独立监听的站点继续运行。已被入站引用的站点不能删除，需先在对应入站选择“不关联”。

站点记录保存在数据库 `decoy_sites` 表，模板位于数据库目录下的 `site-templates/`，自动证书缓存位于 `website-certs/`。迁移服务器时应同时备份数据库、模板目录、证书缓存和自己配置的证书文件。仅数据库备份不含模板及证书文件。

早期内嵌在 XHTTP 入站中的网站配置仍兼容，可在安全配置页继续编辑，也可改选统一管理的站点。

## 安装与验证

本改动合并到此 fork 的 `main` 且发布工作流成功生成 `dev-latest` 安装包后，可使用：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/csa8820/3x-ui/main/install.sh) dev-latest
```

站点管理、模板列表、安装、导入和预览接口位于 `/panel/api/sites/`，沿用原有登录、API token 权限和 CSRF 机制；接口已登记到面板 API 文档。

后端验证包含真实 Xray 内核下的 XHTTP 三种模式、WebSocket、gRPC、HTTPUpgrade、RAW TLS 回落和 REALITY，同时检查网页与双向代理流量。模板验证覆盖真实目录下载、静态资源、许可证保留、路径越界拒绝和内容转义；站点验证覆盖引用保护与配置同步。生产证书尚未使用真实公网域名签发验证。
