安装

{{.Title}} 提供多语言 SDK。以 Node.js 为例，在项目根目录执行以下命令：

npmpnpmyarn
npm install @example/sdk --save
提示SDK 需要 Node.js 18 或更高版本。也可以使用 Python、Go 与 Java 版本的 SDK。

初始化配置

在控制台创建项目后，复制访问密钥并初始化客户端：

index.ts
import { Client } from '@example/sdk';

// 建议通过环境变量注入密钥，避免写入代码仓库
const client = new Client({
  endpoint: 'https://api.{{.Domain}}',
  accessKey: process.env.ACCESS_KEY,
  region: 'cn-east-1',
});

const result = await client.projects.list({ limit: 20 });
console.log(result.items);
参数类型说明
endpointstring服务访问地址
accessKeystring访问密钥，可在控制台生成
regionstring资源所在地域，默认 cn-east-1
timeoutnumber请求超时时间（毫秒），默认 30000
注意访问密钥拥有账号下的完整权限，请勿在前端代码或公开仓库中暴露。

核心概念

在开始构建应用之前，建议先了解以下几个核心概念：

  • 项目（Project）：资源隔离与计费的基本单位。
  • 环境（Environment）：同一项目下的开发、测试与生产环境。
  • 资源（Resource）：数据表、存储桶、函数等具体服务实例。
  • 角色（Role）：定义成员对资源的访问权限。
